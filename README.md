# How to Use This Project
This project is an interactive website. To view it, open the link in any web browser (Chrome, Safari, and Firefox all work) and make sure you have internet access so the map loads properly.
Once the page loads, you'll see a world map colored by UV radiation intensity at each latitude, ranging from deep red near the equator where UV is strongest to dark green toward the poles where it's weakest. Click on any country and a popup will appear explaining the UV levels at that latitude, how those UV levels shaped ancestral skin pigmentation in that region, and a skin tone swatch showing what those ancestral tones look like.
Scroll down below the map to read three short science cards that break down the folate protection side of the hypothesis, the Vitamin D synthesis side, and why skin color is a continuous gradient rather than a set of racial categories. To close a popup, just click anywhere else on the page.
